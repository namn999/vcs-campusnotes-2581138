# CampusNotes - Setup and Usage Guide

## Setup
1. Clone the repository:
   git clone https://github.com/parivesh25/vcs-campusnotes-2581138.git
2. Open the folder in VS Code

## Usage
- Add your notes in notes.txt
- Commit and push changes to share them:
   git add .
   git commit -m "docs: update notes"
   git push
